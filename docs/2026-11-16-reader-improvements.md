# 阅读与筛选改进

- 展示标题最多44个字符（含省略号），完整原始标题保留在正文开头；原文链接与存储内容不变。AI短标题尽量给价格、星级保留空间。
- 同步元数据变化不重复重建列表；正文使用已有签名保留节点。
- 图片右键按文章ID与图片序号处理，不依赖固定URL路径；支持复制与另存为。
- 通知条件可选关键词、分类、来源、1—5星及未评级。每组支持全选/清空，空组不参与，全部内容模式忽略筛选。星级需AI已处理，建议开启等待AI结果。
- AI统计支持今天、7天、30天、全部保留记录、自定义日期，展示每次缓存率与小时缓存率图。服务商未返回缓存字段时显示未知。
- 已有费用快照不变；缺少价格的同模型旧记录按最新维护单价估算，跨模型不套用。估算不是账单。
- 提供默认、暖纸、浅绿、灰蓝阅读背景，保存在本机；深色主题优先。
- 今日总结移除重复文章列表，生成后显示按主题归纳的文章内容；未生成时只展示生成入口与数据分析。推理开关需接口支持thinking参数，默认关闭。
- 五星评价以明确的阅读或使用价值为依据，不要求全网最低价证明，不规定各星比例。已有评级不自动重新付费处理。

公共客户端不捆绑实际订阅、登录凭据或用户历史。个人订阅保存在本机加密状态中。
