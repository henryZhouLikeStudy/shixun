# AI 设置与处理监控

AI 设置保留未保存的草稿。后台同步、测试、编辑认证、切换设置页均不会清空当前模型、服务预设或密钥输入。草稿只保存在当前进程内存；关闭程序不会保留未保存的密钥。

“保存AI设置”一次保存接口参数与填写的 API Key。密钥留空保留当前接口凭据，更换接口会清除旧接口密钥。高级认证沿用独立的请求配置窗口。测试连接会先保存当前配置，再使用虚构示例验证返回格式；连接成功不会自动处理历史文章。

私有来源只有在开启“允许发送私有订阅正文”后才会发送正文。未授权、达到日限额、接口失败和格式不兼容均会出现在处理记录里。文章错误时再次点击 AI 处理将重新尝试。历史文章仍需手动处理，自动处理仅用于同步发现的新增内容。

AI 先识别新闻、教程、研究、观点、购物等文章类型，标题突出相应事件、方法或结论，非购物文章不拼接价格。购物标题以主商品、明确价格和推荐度组合展示，例如“运动鞋｜到手¥129｜推荐 4/5”。`TB【凑单139.13】` 等明确条件价格可补入标题；购物内容没有明确价格时显示“价格未说明”。推荐度仍是模型主观评价。左侧按1—5星和未评级精确筛选，分组与条目均可拖动排序。

“通知使用AI处理结果”切换后立即保存。开启后等待AI成功，按处理后的标题和分类筛选再通知，独立于“自动处理新增内容”；失败、超时、达到自设上限或正文未授权时仅保留文章与错误记录，不弹出原标题。默认快速模式继续先提醒、后异步处理。处理记录中的通知任务单独标注。每日请求上限默认0（不限），可在AI助手主页面设置正数。

## 个性化与智能识别

在AI助手中展开同名区域：

- 允许AI新增通用品类；分类按名称去重，已有手动锁定优先，分类数量达到100时不继续自动新增。
- 只参考最多6篇授权范围内的收藏原文，不使用普通历史或模型评级推断偏好，也不当作行情或价格事实。
- 可编辑个人提示词和系统提示词；结果结构与数据安全要求始终保留。
- 图片识价默认关闭，需要支持图像的模型；开启后最多发送前2张压缩图片，私有来源仍受正文授权约束。不发送原始图片地址或订阅认证信息。图片提取的价格标注“图示”，不代表已核验成交价。

相同内容指纹可跨文章复用结果，新增分类不使已有内容缓存整体失效。公共提示词和收藏参考固定在请求前部，分类排序保持稳定，变化的文章正文放在最后，以利服务商复用共同前缀；不填充无意义Token或混用不同文章结果。收藏变化会更新下次处理的结果缓存键；服务端缓存受其最小Token数、保留期和缓存策略影响，不保证命中率。AI配置或内容变化会重新判断缓存。手动再次处理已有AI结果会重新请求，可能产生费用；历史偏好变化不会自动批量重处理文章。

## 记录与用量

在“设置与偏好 → AI统计”查看指标卡、每小时请求/Token图表，以及处理记录：

- 手动处理、自动处理、通知处理、连接测试与今日总结。
- 排队、处理、成功、失败、拦截、缓存命中和过期结果状态。
- 模型、开始时间、处理耗时及可公开的错误提示。
- 服务商返回的输入、输出、总 Token，以及缓存输入和推理 Token 子项。

没有 usage 的响应显示未知，不使用字符数量估算。缓存和推理Token为输入/输出的子项，不重复加入总量。本地复用率与服务端Token缓存率分别统计；服务端没有返回缓存指标时，不把未知显示为已知命中率。

在“AI助手 → 费用与 models.dev”读取公开目录，按确切模型ID查找并选择服务商。中转模型别名可映射目录ID，不改变调用模型、接口或密钥；查不到时保留手动输入。目录单价为美元/百万Token，支持已知缓存读取折扣，复杂阶梯或音频计价不自动套用。绑定并保存后，24小时后的下一次AI调用刷新目录价格，离线保留上次价格。新请求按价格快照计价；改模型或接口后旧绑定失效，需重新选取。历史未记录价格的调用不会按新目录价格补算；手工单价对旧记录仅作当前单价回溯估算。金额不等于实际账单，中转商计价、税费等可能不同。访问目录不携带AI密钥、文章、私人源或模型查询参数。

统计基于当前保留记录，以前未记录的调用无法补算。记录最多保留500条、30天，界面最多显示最近200条中的100条；每日图表基于本机保留的500条记录，累计Token另行保留在本机。

处理记录、累计用量和凭据均在当前 Windows 用户的加密数据中保存。公开配置备份排除这些数据。记录不保存 API Key、请求认证信息、接口地址、完整正文、完整响应或模型思考过程。

新安装不创建内容分类。订阅包启动器只导入订阅，不再导入附带分类。已有用户分类保留，可自行编辑或删除。

今日总结以文章正文摘要与原始内容速览为主，图表为辅助。AI按主题汇总今天收到文章的事件、观点、方法和变化，列出值得阅读的原始标题，不输出AI消耗报告；最多选取60篇并受正文字符预算约束，超出或私有未授权的文章不参与。不启用AI时显示来源摘录，不冒充AI摘要。AI摘要需手动生成；沿用当前接口与私有正文授权，标明覆盖篇数，失败保留上一份摘要，跨日自动清理。

启动未读摘要按通知时长自动关闭；仍提供打开阅读和手动关闭入口。
