# 1.0.0 验证记录

本地Windows环境完成：

- 44项核心检查：RSS/Atom、编码、DTD拒绝、路径/查询参数、独立认证组合、POST表单和JSON、凭据跨站重定向拒绝、DPAPI往返、正文清理、首次同步基线、去重、删除不恢复、规则更新预览与图片请求合并/缓存。
- 原生凭据窗口检查：Token及密码遮罩、多参数行、请求体和保存往返。
- 15项浏览器界面检查：原生桥接契约、空订阅、订阅/规则认证入口、全局与单源间隔、通知筛选、删除偏好、HTML白名单、内容标题、字号、滚动保位和导航折叠。
- 真实WebView2运行窗口：加载成功；真实网络来源的图片、富文本链接通过本机验证，数据未收入仓库。
- 公开源码与分发采用明确文件名单；不包含生产后台、凭据、私人来源、历史消息或用户截图。

测试不能证明所有站点兼容。动态OAuth、动态签名、验证码及非RSS内容抓取不在通用静态请求配置能力内；网络限流与内容源错误应通过来源状态排查。

核心和原生窗口测试由 `build.ps1 -Test` 执行。页面测试 `tests/ui.cjs` 可通过本机Playwright执行，使用虚构桥接数据，不访问真实来源。`--verify-ui` 仅用于本机诊断，会在本机数据目录生成截图；不要将该目录上传。
