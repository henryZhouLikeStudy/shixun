# 检查与安装更新

默认在每次启动且阅读界面加载后检查一次 GitHub Releases 的稳定版本；不会自动下载或安装。发现新版本后显示提醒，“关于与支持”也提供检查更新和下载并重启更新入口。可关闭启动检查。

更新请求只访问本项目公开 GitHub 版本及其附件，不携带订阅凭据、Cookie 或 AI 配置。网络不可用时可稍后重试；不影响订阅同步。

下载使用公开便携包 `Shixun-{版本}-win-x64.zip` 与 `SHA256SUMS.txt`，校验通过后才解压。仅允许程序、界面和许可证等明确文件，拒绝路径穿越、重复项、过大内容及覆盖私有配置。更新组件等待程序正常退出，备份并替换文件后重新启动；替换失败时尝试恢复原文件。备份留在安装目录的 `.update-backup-*`，下载缓存位于用户数据目录的 `updates`。

订阅、AI 配置和历史保存在用户数据目录，私人外发包附带的订阅文件也不会被公共更新包覆盖。更新版本保留已有 AI 配置；私人包新安装默认不启用 AI，也不提供 AI 账号或密钥。

安装目录需有当前用户写权限；缺少更新组件或无法自动安装时，可从本项目 Releases 下载完整便携包，退出托盘程序后覆盖原目录。
